## When a reference page is not enough

A reference page says what exists; it does not say which of it you need. If you
arrived with a task rather than a name, the guide for it is one of the paths on
[the home page](/): [Build an app](/guide/build-an-app) for application code,
[The toolchain](/guide/toolchain) for the commands, [Targets](/guide/targets)
for where it runs.
