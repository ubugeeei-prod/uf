# Your first project

<div className="lede">
Create a React application with Flow, run it locally, and build it for deployment.
</div>

You need [uf installed](/guide/install) and a JavaScript host such as Node.js.

## Create and install

```sh
uf new my-site
cd my-site
uf install
```

`uf new` creates the directory. To use an existing directory, run `uf init`
there instead. Both commands create files; `uf install` installs dependencies.

The default template is `react`. Use `uf new my-site monorepo` for an application
and a shared library, or `uf new my-library --lib` for a library.
[The CLI reference](/reference/cli) also covers remote templates.

The React template writes:

```text
my-site/
  uf.config.js       project configuration and tasks
  app.js             application entry
  app/
    $layout.js       document layout
    $page.js         home page
    Counter.js       example client component
    useCounter.js    example hook
    $page.test.js    example test
  package.json       dependencies
  .gitignore         generated files to exclude from Git
```

Replace the example counter, hook and test as you build your application.

## Start the development server

```sh
uf dev
```

The server reloads as you edit. React components support Fast Refresh.

## Run checks and builds

The generated `uf.config.js` defines tasks with dependencies:

```js
// @flow
import { defineConfig } from "@uniflowed/config";

export default defineConfig({
  tasks: {
    "verify:format": { command: "uf fmt --check" },
    "verify:source": { command: "uf check" },
    verify: { command: "uf test", dependsOn: ["verify:format", "verify:source"] },
    bundle: { command: "uf build", dependsOn: ["verify"] },
  },
});
```

| Command | Runs |
| --- | --- |
| `uf run verify` | Formatting and source checks in parallel, then tests |
| `uf run bundle` | Verification, then the production build |
| `uf fmt` | Formatting with files updated in place |

`dependsOn` lists tasks that must succeed first. `uf check` includes linting
and type checking, so the example does not run a separate lint task.
Use the same `uf run bundle` command locally and in CI.

You can also run built-in commands such as `uf test` or `uf build` directly.
[Tasks](/guide/tasks) covers custom commands and caching.

uf uses `app/` for routes and `app.js` as the entry by default. To change them,
set `app.router.root` and `app.router.entry`. `defineConfig` provides Flow types
for the configuration; see [all options](/reference/config).

## Add pages and layouts

`app/$page.js` defines the home page:

```js
// @flow
export component Page() {
  return <h1>Hello</h1>;
}
```

`app/$layout.js` wraps the page in an HTML document:

```js
// @flow
import * as React from "@uniflowed/react";

export component Layout(children: React.Node) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

The template uses `children: mixed` so it can be checked before dependencies
are installed. After `uf install`, you can use `React.Node` as shown above.

Use named exports such as `Page` and `Layout`. The router accepts default
exports too, but `uf check` warns on default-exported components.
See [Routing](/guide/routing) for nested routes, parameters and loading states.

## Build for deployment

```sh
uf run bundle
```

The build writes prerendered HTML and client assets to `dist/`. To inspect
bundle sizes, run `uf build --size-report`.
[Deploy a web build](/guide/deploy) covers previewing and publishing the output.
