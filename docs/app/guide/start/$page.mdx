## Before you start

- Use macOS or Linux on x86-64 or ARM64, or Windows on x86-64.
- Install a JavaScript host such as Node.js. Bun and Deno 2.8+ are also supported;
  see [runtime details](/guide/install#the-javascript-host).
- Be familiar with React components and hooks. The guides explain Flow syntax
  as it appears.
